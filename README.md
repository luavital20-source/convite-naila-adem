**Fontes**

- **Aerotis** (fonte de título da identidade) — é uma fonte comercial, não existe
  para web. Por isso o nome "Nailla e Adem" foi extraído do PDF em alta resolução
  como imagem (`fotos/nome-casal.png`) e usado na abertura, na capa, na seção de
  presentes e no rodapé. Assim a caligrafia é exatamente a da identidade visual.
- **Cormorant Garamond** — títulos das seções.
- **Arapey** — corpo de texto.
- **Italianno** — apoio caligráfico, quando o lettering não carrega.
